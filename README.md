# FreshBasket Retail – Sales Performance Analysis

## Project Overview
This Excel-based data analytics project focuses on analyzing retail sales performance, customer purchasing patterns, product performance, and revenue trends.

## Project Objectives
- Analyze overall retail sales performance.
- Identify top-performing products and categories.
- Understand sales trends over time.
- Evaluate customer purchasing patterns.
- Present key business insights through an interactive Excel dashboard.

## Tools Used
- Microsoft Excel

## Analysis Areas
- Sales Performance Analysis
- Product Category Analysis
- Customer Analysis
- Revenue Trend Analysis
- Dashboard Reporting

## Project Deliverables
- Cleaned retail sales dataset
- Excel-based interactive dashboard
- Visual sales performance reports
- Business insights and findings

## Key Performance Indicators (KPIs)

## Key Insights
The project explores sales trends, product performance, customer purchasing behaviour, and revenue distribution to support data-driven business decisions.
